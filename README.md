# 🧋 TIỆM TRÀ SỮA HEEHEE (Heehee Bubble Tea Shop)

Dự án game mô phỏng quản lý kinh doanh & thời gian thực phong cách **Pixel Art / Anime Vector**, nơi bạn khởi nghiệp cùng cô chủ nhỏ HeeHee tại góc phố đêm lung linh. Game được trang bị đầy đủ **Frontend Canvas mượt mà, Backend Node.js, SQLite Database và Hệ thống Chống Gian Lận (Anti-Cheat) đa tầng**.

---

## 🌟 TÍNH NĂNG NỔI BẬT

1. **Đồ Họa Vector & Pixel Art Chi Tiết Cao:**
   - Hoạt họa canvas 2D 60 FPS: Xe đẩy trà sữa đèn Neon vàng hoàng kim, cô chủ HeeHee với tạp dề chuyên nghiệp, lắc bình shaker tỏa sương khói.
   - 10 dạng nhân vật khách hàng độc đáo (Bé Lan học sinh, Dân văn phòng, Cô Ba hàng xóm, Tú TikToker triệu view, Anh Shipper thể thao, Cụ Đồ phố cổ, Gymer vạm vỡ, Cặp đôi gà bông, David Tây ba-lô, Bé Hạnh vé số cùng cún con).
   - Âm thanh chiptune 8-bit procedural qua Web Audio API không tốn băng thông tải tài nguyên.

2. **Hệ Thống Thú Cưng Giữ Quán & Kẻ Trộm Vặt:**
   - 3 linh vật giữ quầy siêu cấp đáng yêu: **Cún Corgi chân ngắn** (+20% tiền tip), **Mèo Tam Thể chiêu tài** (+15% doanh thu), **Chuột lang nước Capybara** (+40% kiên nhẫn).
   - Cơ chế ngẫu nhiên khi quán đông khách: **Kẻ trộm đồ đen đeo khẩu trang** có thể lén lút câu trộm thú cưng! Bạn sẽ phải chi **50% giá trị thú cưng** để nộp tiền chuộc bé về an toàn.

3. **Sự Kiện Ngẫu Nhiên: Anh Shipper Mời Ăn Vặt & Tú TikToker:**
   - Anh Shipper có thể mời ăn vặt vỉa hè (bánh tráng trộn, bắp xào bơ, xiên que...). 75% nhận buff may mắn tăng tiền/kiên nhẫn, 25% nhận hiệu ứng **Đau Bụng** phải tạm nghỉ quầy đúng **15 phút thời gian thực**.
   - TikToker ghé thăm có thể mang lại hiệu ứng viral x2.5 lượng khách hoặc bóc phốt nếu phục vụ chậm trễ. Chủ quán có thể chủ động mời TikToker cứu vớt danh tiếng khi quán dưới 3⭐.

4. **Cơ Chế Giới Hạn Doanh Số Ngày Thực (Daily Cap) & Collab Bạn Bè:**
   - Giới hạn doanh thu mỗi ngày tính theo đồng hồ thực của server để bảo vệ sức khỏe người chơi.
   - Chia sẻ **Mã Quán (Store Code)** để kết bạn Collab liên doanh, nâng cao trần doanh thu mỗi ngày.

5. **Hệ Thống Chống Gian Lận Đa Tầng (Anti-Cheat):**
   - **Xác thực thời gian thực:** Kiểm tra tốc độ pha chế (hoàn thành đơn dưới 0.8s sẽ bị phát hiện speed-hack / auto-clicker).
   - **Ký số HMAC-SHA256:** Bảo vệ tiến trình save game và số dư tài khoản.
   - **Cơ chế niêm phong & Phạt hành chính 50.000.000đ:** Khi gian lận bị phát hiện, xe đẩy bị tịch thu niêm phong. Khi chấp nhận nộp phạt, tài khoản sẽ bị **trừ trực tiếp 50 triệu đồng**, đưa danh tiếng về 1.0⭐.

---

## 🚀 HƯỚNG DẪN KHỞI CHẠY

1. **Cài đặt thư viện:**
   ```bash
   npm install
   ```

2. **Khởi chạy server game:**
   ```bash
   npm start
   ```

3. **Mở trình duyệt:**
   Truy cập [http://localhost:3000](http://localhost:3000) để bắt đầu khởi nghiệp cùng **Tiệm Trà Sữa HeeHee**!
